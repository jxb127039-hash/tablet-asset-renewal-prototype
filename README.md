# 平板已购资产 × 购物车智能换新原型

面向购物车中已有平板、历史订单中存在旧平板的用户。原型验证“自动匹配旧设备、比较换新时机、展示净换新成本”是否比普通以旧换新入口更容易理解和转化。

## 核心口径

- 目标受众：购物车中有平板且历史订单中存在可回收平板的用户。
- 核心卖点（USP）：无需重新找型号，直接比较今天与未来的净换新成本。
- 行动号召（CTA）：`测算并抵扣`。
- 90天预计少值只用于时机比较，不计入今天优惠。
- 旧机只有在用户确认后才应用抵扣并改变购物车应付金额。

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 验证

```bash
pnpm run typecheck
pnpm test
pnpm run build
pnpm run test:e2e
```

## 声明

非京东正式功能，仅用于概念评审。所有订单、价格、用户和回收数据均为模拟，不调用京东订单、回收、补贴或结算接口，不产生真实交易。
