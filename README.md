# 平板已购资产 × 购物车智能换新原型

面向购物车中已有平板、历史订单中存在可回收3C资产的用户。原型验证“自动匹配多件跨品类设备、比较换新时机、展示净换新成本”是否比普通以旧换新入口更容易理解和转化。

## 核心口径

- 目标受众：购物车中有平板且历史订单中存在可回收平板的用户。
- 核心卖点（USP）：无需逐件重新找型号，可多选平板、手机和耳机组合抵扣，并直接比较今天与未来的净换新成本。
- 行动号召（CTA）：`测算并抵扣`。
- 90天预计少值只用于时机比较，不计入今天优惠。
- 每件资产均展示今天、30天、60天与90天的预计残值曲线。
- 资产默认不选中，只有在用户明确选择、确认状态并应用后才改变购物车应付金额。
- 多件资产回收估值累加，但一单只计算一次换新补贴。

## 本地运行

```bash
pnpm install
pnpm run dev
```

## 声明

非京东正式功能，仅用于概念评审。所有订单、价格、用户和回收数据均为模拟，不调用京东订单、回收、补贴或结算接口，不产生真实交易。
